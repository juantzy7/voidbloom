VOIDBLOOM is a neon void-garden twin-stick arena survival game that runs entirely in the browser. You are the last bloom-keeper spirit: hold back waves of withered husks, gather the seeds they drop, and keep the light alive. Move with WASD or the arrow keys, aim with the mouse, hold left mouse or Space to fire, and dash with Shift or right-click. Four enemy kinds plus a WITHERHEART boss every fifth wave, a combo multiplier, and a choice of three upgrade cards on every level-up. All art is drawn in canvas code and all sound is synthesized WebAudio: no assets, no build step, no network.

## Run it

```sh
node serve.ts --port 8080
```

Then open http://localhost:8080 in a desktop browser and press Start.
